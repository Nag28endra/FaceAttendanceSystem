# Face Attendance System

This project uses Python, OpenCV, and `face_recognition` to capture student images, convert them into face encodings, and mark attendance in an SQLite database.

## Features

- Enroll students by capturing a photo and saving their face encoding
- Run live face recognition to mark attendance
- Store student details and attendance records in `attendance_database.db`
- Send the attendance database file by email (optional)

## Project structure

- `smart_attendance.py` - main GUI application
- `face_encoding/` - stored face encoding files for recognized students
- `clicked_photo/` - captured enrollment images
- `attendance_database.db` - SQLite database generated by the app
- `icon/` - application icon assets

## Requirements

Install all dependencies from `requirements.txt`:

```bash
pip install -r requirements.txt
```

The `requirements.txt` file includes:

- `opencv-python`
- `face-recognition`
- `numpy`
- `Pillow`

> Note: `face_recognition` may need `dlib`, `CMake`, and Visual Studio Build Tools on Windows before installation completes.

## Run the application

From the project root, run:

```bash
python smart_attendance.py
```

### First-time setup

1. Make sure the webcam is available.
2. Confirm that the `icon/icon.png` file exists.
3. If the `face_encoding/` and `clicked_photo/` folders are missing, the app will create them automatically when it starts.

### Enrollment flow

1. Click **Click me !** in the enrollment section.
2. Enter the student name, college ID, batch, and department.
3. Click **save!**.
4. Click **capture !** to take a photo and save the face encoding.

### Attendance flow

1. Click **Click me !** under **Start attendance**.
2. The camera window will open and recognized students will be highlighted.
3. Press `q` in the camera window to stop attendance capture.

## Database setup

The app creates the SQLite tables automatically when you click **Generate DB** and enter the password `neeraj123`.

## Email setup

To send the attendance database by email:

1. Update the sender details inside `smart_attendance.py`.
2. Enter the recipient email in the email entry field.
3. Click **Save** and then **Send**.

## Notes

- A webcam is required for both enrollment and attendance capture.
- The app expects the `icon/icon.png` file to exist.
- The code stores the face encodings in `face_encoding/` and the captured enrollment photos in `clicked_photo/`.
